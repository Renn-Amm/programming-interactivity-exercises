# Lecture 3 — Layout

Exercises, playgrounds and a game for the layout lecture: normal flow, position,
flexbox and grid, all on the Harbour Night Market page.

Open `index.html` in a browser for the full list. Everything is static HTML —
serve the folder with any local server (e.g. `npx live-server`) so the live
editors and checks work.

## Start here

1. Copy `project/starter/` out of this repo into your own folder (or extract
   `project/starter.zip` there) and open that copy. Don't edit inside the repo:
   the next `git pull` would fight your changes.
2. `css/outfit.css` is how the page looks (swap in your `style.css` from last
   time if you like). `css/layout.css` is yours: where things go.
3. Work through the exercises in order, then bring the code into `layout.css`.

## Playgrounds

`playgrounds/` — Stall Setter (a layout game: 6 position, 13 flexbox, 10 grid, 6 deep-cut
levels), Position lab, Flex lab, Grid lab. `project/showcase/` is the finished
page with a switcher that adds the layout one act at a time (keys 0–4).
`cheatsheet.html` prints on one A4 page.
